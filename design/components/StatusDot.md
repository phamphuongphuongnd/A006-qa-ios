# StatusDot

The "never silently miss" signal. A 10px dot with a 4px soft halo, always next to words.

- `ok` (soft green) = working · `warn` (orange) = needs attention, always with a Fix action · `off` (grey) = off · `live` (red, blinks) = a trip is recording.
- Use on Home, Miles, Automatic trips, Backup and widgets. Status never changes silently: a change to `warn` also raises a Home card and a notification.
