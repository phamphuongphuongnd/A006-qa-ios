# Dialog

Centered card, `radius-sheet`, over `scrim`. Title is the question in `headline`; one sentence of consequence in `ink-muted`; buttons stacked full-width, the safe choice last.

- Destructive actions (Delete, Discard, Delete everything) use an `error` fill with `on-primary` text. Everything else uses `primary`.
- Permission errors add a 56px icon disc and always offer "Open settings" / "Not now".
- "Delete all data" asks twice; the second dialog needs the word DELETE typed.
