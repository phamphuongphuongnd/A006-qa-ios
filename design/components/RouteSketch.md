# RouteSketch

A trip drawn as a line on `surface` — no base map, no addresses (privacy). Start = filled dot, end = rounded square.

- Work segments: 4px `work` line over a 10px `line` halo. Personal segments: `personal`, dotted.
- Stops: numbered 18px circles; tapping one opens the stop sheet (mark personal / split here).
- Area text only: "Leeds → Wakefield area".
