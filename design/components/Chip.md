# Chip

Rounded `radius-full` pills. Category chips on Sort are 48px (`lg`); filter and note chips are 40px with a 48px hit area.

- **Suggested** (Pro): first chip gets a 2px `sunday` ring on `sunday-soft`. Label above: "Suggested" with the bolt icon. Free plan shows "Most used" and plain chips — same layout, no ring.
- **Selected filter**: `primary` fill. **Ghost** ("More…"): `line` outline, `ink-muted` text.
- **Scope**: Work = `work` fill, Personal = `personal` fill, `on-scope` text.
- Tapping a category chip on Sort *is* the save — no confirm button.
